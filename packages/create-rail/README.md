# Rail

One command. Clean repo. Agent on rails.

Rail creates a Vite or Next.js React app with strict TypeScript, linting,
formatting, pre-commit checks, and dependency age gates already wired.

## Usage

### npm

```bash
npm create rail@latest
```

### yarn

```bash
yarn create rail
```

### pnpm

```bash
pnpm create rail@latest
```

### bun

```bash
bun create rail@latest
```

Full CLI usage and flags:
[docs/CLI.md](https://github.com/sago-cream/create-rail/blob/main/docs/CLI.md)
